# 我的编程之路，从一部手机开始

## 一、2008 年春节，表哥的那部手机

那年春节，表哥从大学回来。

他带回来一部手机，我记得是装了 Java 平台的那种，上面能玩不少游戏——斗地主，还有枪战、飞机一类的。我一下子就被吸引住了。

玩着玩着，我又开始琢磨：这些游戏都是哪来的？翻来覆去折腾之后才明白，它们得下载、得安装。就是在这个过程中，我第一次摸到了互联网的边。

## 二、一本《高中信息技术》，和一整个高一

上了高一，学校发了一本课本，叫《高中信息技术》。里面有一章讲 Visual Basic 编程。

那一章，我看得入了迷。从那以后，我开始自己找这类书来看，硬是把 Visual Basic 自学了下来。

代价也跟着来了：为了"学编程"，我常常偷偷往网吧跑。学着学着，也染上了打游戏的毛病。这毛病一直拖到高三——那年高考，我名落孙山，只好重新回到高中复读。

## 三、一台文曲星，才是我真正的起点

把话再说回高中。大概是高二的时候，有个同学带了一台学习机，就是早期金远见出的文曲星。

神奇的是，那台文曲星上支持一种编程语言，其实就是今天说的 GVBasic。它能写程序，能画图，还能输出些东西。我把它借过来，每天晚上偷偷地玩。

要说编程之门真正打开，就是在那个时候。想不到吧，我的编程之路，竟然是从一台文曲星开始的。

## 四、MRP：还没铺开就已落幕

到了高三，我又接触到另一个手机平台，叫 MRP，是早期的国产平台（冒泡），了解到它开发用的是 C 语言。

后来偶然得到一台破旧的老电脑，我在上面装了 MRP 的开发环境，一头扎进去折腾，想着自己也开发点东西。

可互联网的大潮来得太快，MRP 很快走向没落。我的高中生涯，也到此结束。

## 五、2014 年，大学，和第一桶金

2014 年走进大学，人生翻开了新的一页。

那几年，我像久旱逢雨一样吸收着外面的世界。图书馆成了我待得最久的地方，书一本接一本地看。大一那年，我学会了 C 语言，也把 Visual Basic 又往深里学了一层。之后便不停地尝试，写游戏、写软件，什么都想动手做一做。

到大三下学期，我的编程水平已经算相当高了，能独立做一些软件系统。

也正是在大三，我们赶上了国内那波轰轰烈烈的互联网创业热潮。校外不少老板跑到学校来找大学生做系统，我就是其中一员。靠着这股热度，我赚到了好几万块——我人生里的第一桶金。

## 六、写在最后

从 2010 年算起，到今天，这条路已经走了十六年有余。

回头看，一切都始于 2008 年春节表哥手里的那部手机，始于高中课本里那一章 Visual Basic，始于一台借来的文曲星。没有人指路，全是自己一点点摸索出来的。

---

**这条路会走多远我不知道，但我知道它从哪里开始。**
